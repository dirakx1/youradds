Cómo obtener tu token de acceso de Meta Ads

Necesitas dos datos para conectar Meta en youradds: el token de acceso y el ID de tu cuenta publicitaria. Esta guía usa un «usuario del sistema», que genera un token que no vence cada pocas horas. Tarda unos 10 minutos.

Antes de empezar

  • Una cuenta de Facebook que sea administradora de tu Business Manager (business.facebook.com).
  • Una cuenta publicitaria y, si vas a publicar, una página de Facebook dentro de ese Business Manager.

Paso a paso

  1. Crea una app de Meta. Entra a developers.facebook.com/apps, pulsa Crear app, elige el caso de uso Otro y el tipo Empresa (Business). Ponle un nombre (por ejemplo «youradds») y asócialo a tu Business Manager. Luego agrega el producto API de Marketing.
  2. Abre la configuración del negocio. Ve a business.facebook.com/settings y elige tu negocio.
  3. Crea un usuario del sistema. En Usuarios → Usuarios del sistema pulsa Agregar, escribe un nombre (por ejemplo «youradds») y elige el rol Administrador.
  4. Dale acceso a tu cuenta publicitaria. Con el usuario seleccionado, pulsa Asignar activos → Cuentas publicitarias, marca tu cuenta y activa Control total (administrar campañas). Si vas a publicar anuncios, asigna también tu Página.
  5. Genera el token. Pulsa Generar nuevo token, elige tu app y, si te lo ofrece, la duración que nunca vence. Marca los permisos ads_management, ads_read y business_management. Pulsa Generar token.
  6. Copia el token. Copia el texto largo que aparece (empieza por EAA…). Meta lo muestra una sola vez: guárdalo en un lugar seguro y no lo compartas con nadie.
  7. Encuentra el ID de tu cuenta publicitaria. En Ads Manager el ID aparece en el selector de cuenta, o en la URL como act=1234567890. En youradds puedes escribirlo con o sin act_.
  8. Pégalos en youradds. Abre Conexiones, pega el token y el ID en la tarjeta de Meta y pulsa Guardar. Después pulsa Probar e importar campañas para comprobar que funciona.

Problemas comunes

  • «Credenciales rechazadas»: revisa que copiaste el token completo, sin espacios, y que el usuario del sistema tiene la cuenta publicitaria asignada.
  • No aparece la opción de que nunca venza: el token igual sirve; si caduca, genera uno nuevo y reemplázalo en Conexiones.
  • Seguridad: youradds guarda tu token cifrado. Si crees que se filtró, revócalo en Usuarios del sistema.
